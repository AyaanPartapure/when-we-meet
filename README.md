# When We Meet 💙
**Some things are better said in person.**

## 💭 Why I Built It

I prefer talking in person over texting. Sometimes I think of something I want to share, but by the time we meet, I've forgotten it.

So I built **When We Meet** — a little space to save those thoughts until we're together.

## ✨ What Makes It Special

- 💌 **One space per person** — keep thoughts personal.
- 🌿 **Topics & branches** — organize stories, questions and plans.
- 🩵 **Clean UI** — calm, simple and distraction-free.
- 💬 **Meet Mode** — remember what you wanted to say.
- 🔒 **Private & local-first** — saved using browser IndexedDB, without an external database or backend.
- 💾 **Backups** — optional `journal.txt` and `journal-backup.json` files.

**Tech Stack:** HTML · CSS · JavaScript · IndexedDB

*Keep the thought now. Say it when you meet.* 💙
